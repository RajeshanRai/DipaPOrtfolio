# Dipa Rai — Pixelx Portfolio (Django Starter)

This repository is a starter scaffold for a pixelx-style portfolio for Dipa Rai built with Django, Tailwind, and HTMX.

Quick start

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Tailwind build (requires Node.js):

```bash
npm install
npx tailwindcss -i ./static_src/css/input.css -o ./static/css/tailwind.css --watch
```
